Unit 01 · 9 lecture hours

Fundamentals of Image Processing

A digital image is a finite grid of pixel values. Start with what those values mean, then learn how they are sampled and connected.

Faculty PDFs loaded

🧠 Big idea

An image can be described as a two-dimensional function f(x,y). The coordinates tell where a pixel is; the function value tells its intensity or gray level.

f(x, y) → intensity at location (x, y)

📷 Think of tiles

A photo is like a grid of tiny tiles. Each tile is a pixel. In an 8-bit grayscale image, a pixel can represent 256 possible intensity levels.

128
255
Black → middle gray → white

Sampling vs quantization

Sampling digitizes the coordinate values: it decides which spatial locations are measured.

Quantization digitizes the amplitude/intensity values: it assigns each measurement to an allowed level.

Memory hook: Sampling = “where/how many locations?” Quantization = “which brightness level?”
L = 2ᵏ intensity levels when k bits are used

Image storage calculation

For an M × N image with k bits per pixel:

b = M × N × k bits

Example: 256 × 256 pixels × 8 bits = 524,288 bits = 65,536 bytes = 64 KiB (excluding metadata/compression).

Interpolation comparison

Nearest neighbour

Copies the closest original pixel value. Fast, but zoomed edges may look blocky.

Bilinear

Uses four nearest neighbours to estimate a value. Smoother result, with moderate computation.

Bicubic

Uses a larger neighbourhood (commonly 16 nearby samples) and can preserve detail better, at higher computational cost.

Image Enhancement in the Spatial Domain

Spatial-domain methods operate directly on image pixels. Understand each method by the change it makes to intensity values.

Gray-level transformations

Apply a rule to every pixel. An input intensity r is mapped to output intensity s.

s = T(r)

Negative reverses dark and bright values. Log transformation expands darker values. Power-law (gamma) changes brightness/contrast according to γ.

Remember: one input intensity goes through a mapping rule and produces one output intensity.

Histogram processing

A histogram counts how many pixels have each intensity; it says how common a brightness is, not where those pixels sit.

  • Equalization: remaps intensities using the cumulative histogram to improve global contrast.
  • Matching: remaps the image to approximate a specified target histogram.
  • Local enhancement: adjusts a region using local information.

Smoothing filters

Combine nearby pixel values to reduce noise or small rapid changes. A mean filter replaces a pixel with the average of its neighbourhood.

Output = average(neighbourhood)

Trade-off: smoothing can blur fine details and edges.

Sharpening filters

Emphasise rapid intensity changes, making edges and fine details more noticeable. Derivative-based filters such as the Laplacian are common examples.

Contrast: smoothing reduces rapid changes; sharpening emphasises them.

Arithmetic and logical operations

Addition / subtraction

Combine images or compare intensity values; subtraction can reveal differences.

Multiplication / division

Scale intensities or normalise values, depending on the application.

Logical operations

AND, OR, NOT and masks select or combine binary regions and image areas.

Recall cards

Unit 1 · essentials

  • Digital image: finite, discrete grid of pixels.
  • Sampling: digitises spatial coordinates.
  • Quantization: digitises amplitude/intensity.
  • For L = 2ᵏ levels, k bits represent each pixel.
  • 4-neighbours share an edge; diagonal neighbours touch at corners; 8-neighbours combine both.
  • Distances: Euclidean, city-block (D4), chessboard (D8).
  • Interpolation estimates unknown pixel values from known neighbours.

Unit 2 · essentials

  • Spatial domain = directly changing pixel values.
  • Gray-level mapping: s = T(r).
  • Negative: s = L − 1 − r for L levels.
  • Histogram = frequency of intensity levels.
  • Equalization uses cumulative histogram to remap values.
  • Smoothing reduces noise/rapid changes, possibly blurring details.
  • Sharpening emphasises edges and fine detail.
